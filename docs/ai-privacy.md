# AI 与隐私说明

## 两种 AI 路径

### 站点默认模式（v1 默认关闭）

公开的 v1 部署不提供共享站点 AI（`SITE_AI_ENABLED` 未开启、没有 `DEEPSEEK_API_KEY`）。前端在调用站点 AI 前先请求 `GET /api/deepseek/status`；返回 `disabled`（或该接口不存在）时，**不会把 Prompt 发到本站**，而是提示“本站未启用内置 AI”，引导用户使用个人配置或 ChatGPT 协作模式。即使有客户端直接 `POST /api/deepseek/chat`，服务端也会在读取请求体之前返回 503。

以下描述适用于将来显式开启站点 AI 的部署：浏览器把 Prompt 发到本站 `/api/deepseek/chat`。Render 服务端读取环境变量中的 `DEEPSEEK_API_KEY`，向固定的 DeepSeek Chat Completions 上游发起请求，再把结构化结果返回浏览器。本站不应将年鉴保存到数据库；但 Prompt 会在请求期间经过本站和上游 AI 供应商，因此用户应避免把不希望离开设备的内容写进短评。

### 当前会话个人模式

用户可以在“AI 与隐私”中填写个人服务的 endpoint、模型和 Key。配置仅保存在当前浏览器的 `sessionStorage`，关闭会话后由浏览器清理；请求直接从浏览器发往用户填写的服务，不经过本站 Render。`sessionStorage` 不是密码管理器，恶意同源脚本、浏览器扩展或共享设备上的其他代码仍可能读取它。

只要没有点击“启用个人配置”，鉴赏档案就使用站点默认代理（v1 中该代理关闭，见上文）；启用个人模式后，应用不会在个人请求失败时悄悄改用站点 Key，避免把本应直连个人服务的年鉴发送到另一条路径。需要切回 Render 时，请点击“恢复站点默认服务”。个人 DeepSeek/兼容服务还必须允许当前网页的 CORS 请求。

个人模式的 endpoint 必须由用户信任，并且需要允许本站的 CORS。服务商可能保留请求内容、Prompt 和日志，保留期限由服务商自己的政策决定。

## 哪些功能使用 AI

只有观看历程 → 口味地图 → “AI 回顾（实验性）”中的鉴赏档案会调用 AI；全站画像只生成一段供用户自行复制到 ChatGPT 的绘图 Prompt。“为你推荐”、口味地图和看番回忆都是本地确定性逻辑，不调用 AI。Phase B4 起小游戏与快速测评已移除，不再有游戏或测评 Prompt。

## Prompt 中可能包含的个人数据

鉴赏 Prompt 的实际内容（`services/geminiService.ts#buildTasteAnalysisPrompt`）：

- “我的番剧”中最多 512 部作品的作品名与别名，以及 AniList 公开信息：播出年份、形式、题材、站内评分和人气。
- 每部作品的观看状态（想看/在看/已看完）和感受（或“未标记”）。
- 重点作品（最多 48 部）以及喜欢/不喜欢作品的短评，截断到 180/120 字。
- 本地计算的口味证据：计数、题材倾向、年代与形式分布、缺少观看日期的作品数量（见 `docs/taste-model.md`）。
- **不包含**收录、开始和看完的具体日期。

口味地图的“AI 回顾”区域和鉴赏档案中的 ChatGPT 区域都会在操作前用三种语言写明这些内容。“为你推荐”另外会把你喜欢、非常喜欢和不喜欢的作品的 AniList ID 发给 AniList 以获取推荐关系（不含感受、短评或日期）。

不要在短评中输入真实姓名、联系方式、账号凭证、支付信息或其他敏感个人数据。

## 输出语言

AI 生成的鉴赏档案使用当前界面语言（English / 日本語 / 简体中文）。Prompt 说明本身保持中文，只追加一段输出语言要求；JSON 字段名固定不变。成功的鉴赏档案按语言分别缓存在当前页面内存中，切换语言后会重新请求，不会把一种语言的档案当作另一种语言展示。详见 `docs/i18n.md`。

## 本地数据

年鉴主体、观看状态、反应和短评保存在当前 origin 的 `localStorage`；AI 个人配置保存在 `sessionStorage`。这些数据不会自动同步到服务器，也不会因为站点默认 AI 代理而写入本站数据库。JSON/SQL 导出由用户主动下载或复制，导出文件本身应按敏感个人资料保护。

## 安全边界

- 服务端 API Key 只从 Render 环境变量读取，不能使用 `VITE_` 前缀。
- 代理固定模型和请求上限，并设置 CORS、限流、并发、超时和上游错误映射。
- AI 返回值必须在进入 UI 前解析和校验；模型输出不是可信指令，也不能直接执行为 HTML/SQL/JavaScript。
- JSON/SQL 备份仅作为导入数据，不能被当作可执行 SQL 发送到数据库。

## 删除与撤回

用户可以通过浏览器设置清除本地年鉴和当前会话 AI 配置，也可以删除下载的 JSON/SQL 文件。本站当前没有账号级数据删除或跨设备数据存储接口；如果上游 AI 供应商已经接收过 Prompt，删除浏览器数据不会自动删除供应商侧日志。

## 产品决策待确认

- 是否加入 Cloudflare Turnstile 或登录/配额层。

- 是否将当前 localStorage 年鉴迁移到 IndexedDB，或未来提供用户加密的跨设备同步。
