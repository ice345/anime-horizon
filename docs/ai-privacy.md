# AI 与隐私说明

## 两种 AI 路径

### 站点默认模式

浏览器把 Prompt 发到本站 `/api/deepseek/chat`。Render 服务端读取环境变量中的 `DEEPSEEK_API_KEY`，向固定的 DeepSeek Chat Completions 上游发起请求，再把结构化结果返回浏览器。本站不应将年鉴保存到数据库；但 Prompt 会在请求期间经过本站和上游 AI 供应商，因此用户应避免把不希望离开设备的内容写进短评。

### 当前会话个人模式

用户可以在“AI 与隐私”中填写个人服务的 endpoint、模型和 Key。配置仅保存在当前浏览器的 `sessionStorage`，关闭会话后由浏览器清理；请求直接从浏览器发往用户填写的服务，不经过本站 Render。`sessionStorage` 不是密码管理器，恶意同源脚本、浏览器扩展或共享设备上的其他代码仍可能读取它。

只要没有点击“启用个人配置”，鉴赏档案就使用站点默认 Render 代理；启用个人模式后，应用不会在个人请求失败时悄悄改用站点 Key，避免把本应直连个人服务的年鉴发送到另一条路径。需要切回 Render 时，请点击“恢复站点默认服务”。个人 DeepSeek/兼容服务还必须允许当前网页的 CORS 请求。

个人模式的 endpoint 必须由用户信任，并且需要允许本站的 CORS。服务商可能保留请求内容、Prompt 和日志，保留期限由服务商自己的政策决定。

## 哪些功能使用 AI

只有观看历程 → 口味地图 → “AI 回顾（实验性）”中的鉴赏档案会调用 AI；全站画像只生成一段供用户自行复制到 ChatGPT 的绘图 Prompt。“为你推荐”、口味地图和看番回忆都是本地确定性逻辑，不调用 AI。Phase B4 起小游戏与快速测评已移除，不再有游戏或测评 Prompt。

## Prompt 中可能包含的个人数据

鉴赏 Prompt 可能包含：

- 收录作品名称、年份、题材、观看状态和喜欢程度。
- 用户主动填写的短评。
- 本地计算的口味证据（计数与倾向，见 `docs/taste-model.md`）。

不要在短评中输入真实姓名、联系方式、账号凭证、支付信息或其他敏感个人数据。

## 输出语言

AI 生成的鉴赏档案使用当前界面语言（English / 日本語 / 简体中文）。Prompt 说明本身保持中文，只追加一段输出语言要求；JSON 字段名固定不变。成功的鉴赏档案按语言分别缓存在当前页面内存中，切换语言后会重新请求，不会把一种语言的档案当作另一种语言展示。详见 `docs/i18n.md`。

## 本地数据

年鉴主体、观看状态、反应和短评保存在当前 origin 的 `localStorage`；AI 个人配置保存在 `sessionStorage`。这些数据不会自动同步到服务器，也不会因为站点默认 AI 代理而写入本站数据库。JSON/SQL 导出由用户主动下载或复制，导出文件本身应按敏感个人资料保护。

## 安全边界

- 服务端 API Key 只从 Render 环境变量读取，不能使用 `VITE_` 前缀。
- 代理固定模型和请求上限，并设置 CORS、限流、并发、超时和上游错误映射。
- AI 返回值必须在进入 UI 前解析和校验；模型输出不是可信指令，也不能直接执行为 HTML/SQL/JavaScript。
- JSON/SQL 备份仅作为导入数据，不能被当作可执行 SQL 发送到数据库。

## 删除与撤回

用户可以通过浏览器设置清除本地年鉴和当前会话 AI 配置，也可以删除下载的 JSON/SQL 文件。本站当前没有账号级数据删除或跨设备数据存储接口；如果上游 AI 供应商已经接收过 Prompt，删除浏览器数据不会自动删除供应商侧日志。
